# 装箱计算器 使用说明

## 打开

双击 `装箱计算器.html`，会用电脑默认的浏览器打开。推荐使用最新版的 Chrome 或 Edge，Mac 上的 Safari 也可以使用。

- 不需要联网，不需要安装，填写的数据不会发送到任何地方。
- 可以把这个文件复制到任何电脑上使用。

## 填写

| 项目                | 说明                                                        |
| ------------------- | ----------------------------------------------------------- |
| 大箱子 长 / 宽 / 高 | 大箱子的**外径**，单位 cm。下方会显示扣除壁厚后的内径       |
| 空箱重量            | 大箱子本身的重量，单位 g                                    |
| 小箱子 长 / 宽 / 高 | 小箱子的**外径**，单位 cm                                   |
| 单个重量            | 一个小箱子（含内容物）的重量，单位 g                        |
| 大箱子壁厚          | 纸板厚度，单位 cm。内径 = 外径 − 2 × 壁厚                   |
| 体积重除数          | 快递公司计算体积重用的除数，常见 6000（国内）、5000（国际） |
| 混合方向 / 单一方向 | 见下文                                                      |

- 尺寸最多填 1 位小数（精确到 0.1cm），最大 1000cm。
- 填错时，输入框会变红并提示原因。

填好后点「**开始计算**」。

## 两种模式

**混合方向**（默认）：小箱子可以横放、竖放、侧放，不同箱子朝向可以不同。通常能装得更多。

**单一方向**：所有小箱子朝向一致，现场装箱更简单、不容易出错。如果混合方向能多装，页面会提示能多装几个。

切换模式不需要重新计算。

## 看结果

### 最多可装 N 个

结果下方会有一个标记：

| 标记                               | 含义                                                                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| ✓ 已证明是最大值，不可能装得更多   | 这个数字就是真正的最大值                                                                                                          |
| ✓ 所有箱子同一方向时，这就是最大值 | 单一方向模式下，这个数字一定是最大值                                                                                              |
| 当前找到的最好方案                 | 情况比较复杂，程序在 2 秒内找到的最好结果。页面同时给出理论上限，真实最大值在两者之间。理论上限是按体积粗略估算的，实际往往达不到 |

### 3D 图

- 鼠标拖拽旋转，滚轮缩放，双击恢复初始视角。
- 同一种朝向的小箱子颜色相同，颜色和下方「摆放方向」列表一致。
- 箱子特别多时（超过 3 万个），只画出一部分，页面会注明。

### 摆放方向

列出每种朝向用了几个。尺寸按「沿大箱子的长 × 宽 × 高方向」排列。比如 `23.5 × 32.5 × 4` 表示小箱子 23.5cm 的边沿大箱子的长，32.5cm 的边沿大箱子的宽，4cm 的边朝上。

### 装箱方案明细

把大箱子内部分成若干区域，每个区域内的箱子朝向相同、整齐排列。

- **起点**：区域的角落距大箱子内腔角落的距离（长, 宽, 高），单位 cm。
- **排列**：如 `2 × 1 × 6 = 12 个`，表示沿长、宽、高方向各排 2、1、6 个。

### 重量

- **实际总重量** = 空箱重量 + 单个小箱子重量 × 数量
- **体积重** = 大箱子外径 长 × 宽 × 高（cm）÷ 体积重除数
- **计费重量** = 两者中较大的一个

### 缩小大箱子建议（仅单一方向）

如果大箱子还有空隙，会建议一个刚好装下同样数量的外径尺寸。点「使用这个尺寸」会自动填进去，再点「开始计算」即可验证。

## 常见问题

**改了数字后结果变灰了？**
结果是按上一次的参数算的，点「开始计算」就会更新。

**为什么有时显示「当前找到的最好方案」而不是「已证明」？**
三维装箱是公认的数学难题，箱子多、尺寸不规整时，没办法在很短时间内证明某个结果一定是最大值。这时页面给出找到的最好方案和理论上限，方案本身一定是能实际摆出来的。

**结果和我手工算的不一样？**
请确认填的是**外径**，并检查壁厚。内径会显示在大箱子各尺寸输入框下方。

**页面打不开或显示异常？**
请换用最新版的 Chrome 或 Edge 再试。如果仍有问题，把页面截图发给开发人员。
